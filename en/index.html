Bachelor's Thesis · 2025–2026

Random Forest on satellite imagery for plant detection and counting

Author Tobia Sacchetto
Advisor Prof. Edoardo Sciavicco
University of Ferrara

This project tackles a real precision-agriculture problem: counting avocado trees in agricultural land from satellite imagery, without manual field surveys. The system classifies the image pixel by pixel using infrared spectral bands, then groups the pixels classified as "plant" and estimates their count with a linear regression model.

I developed and compared two variants: one using both the NIR and SWIR bands, trained on a high-resolution proprietary satellite dataset (30 cm/pixel), and a lighter one using only the NIR band, also incorporating an open-source dataset to recognize an additional species.

The dual-band version discriminates better between species, while both models lose some precision on the less-represented classes in the dataset — a typical limitation with imbalanced data.
